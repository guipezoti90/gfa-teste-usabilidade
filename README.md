# Protótipo navegável — teste de usabilidade

Página estática, sem dependências e sem build. Abre offline com dois cliques.

- `participante/index.html` — o protótipo que o participante usa na sessão
- `index.html` — redireciona para o protótipo

## Rodar localmente

Abra `participante/index.html` no navegador. Não precisa de servidor.

## Publicar

Este repositório é servido pelo GitHub Pages a partir do branch `main`, raiz do projeto.
O arquivo `.nojekyll` desliga o processamento do Jekyll; `robots.txt` e a meta `robots`
mantêm as páginas fora dos buscadores.
